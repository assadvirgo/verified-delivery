# Manual verification

Every feature is checked by a person before it counts as finished. Automated tests still run on every change; this is in addition to them.

## For testers

1. Read `ENVIRONMENT.md` once: where to test, test accounts, demo data, how to reset.
2. Pick a checklist below with status **awaiting**.
3. Follow it step by step and fill in the results in the checklist file itself.
4. Complete the sign-off table and set the checklist's status to passed or failed.
5. Save the file and send it back the way your lead has agreed (commit it, or send the file).

If a checklist is unclear, wrong, or assumes something that is not there, that is a finding too: write it under "Problems found".
